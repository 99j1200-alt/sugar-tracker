# متابعة السكر (SugarTracker)

تطبيق آيفون بسيط بالعربي لتسجيل قراءات السكر ومتابعتها.

- تسجيل القراءة مع وقتها (صائم، قبل الأكل، بعد الأكل، قبل النوم) وملاحظة
- ألوان حسب النطاق المستهدف (منخفض / طبيعي / مرتفع)
- رسم بياني وإحصائيات لـ 7 / 30 / 90 يوم: المتوسط، نسبة القراءات داخل النطاق، A1c تقديري
- الوحدة mg/dL أو mmol/L
- تصدير القراءات CSV
- كل البيانات محفوظة على الجهاز فقط

## التحميل

كل تعديل يندفع على `main` يبني ملف `SugarTracker.ipa` (بدون توقيع) عن طريق GitHub Actions وينشره في
[Releases ← latest](../../releases/tag/latest). حمّله وافتحه في ESign عشان توقّعه وتثبّته.

> التطبيق للمتابعة الشخصية فقط، وما يغني عن استشارة الطبيب.
